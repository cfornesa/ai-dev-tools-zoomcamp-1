# Cross-repository parity inventory

The Django/React `ai-dev-tools-zoomcamp-1` project has a fail-closed
application-admin boundary and narrow admin settings/plan APIs, but its current
scope does not include the broader CMS page/content console or user profile
surface found in the local `augment-humankind-platform` and
`augment-humankind-react-node` references. The reference React/Node task
records identify separate admin domains (pages, media, pieces, recycle bin),
public profiles, site/profile theme controls, and a consistent auth shell.

This is a behavior inventory only. Preserve this project's Django routes,
local-first project/media guarantees, entitlement service, and opaque-origin
runtime boundary. Port the reference domains as separate criterion-ready
issues rather than copying schemas or adding arbitrary executable theme code to
the parent document. Current distillation: #515–#522.
